# 隐蔽小窗

本插件代码全部由GPT-5.5开发、测试与推送。

隐蔽小窗是一个 SillyTavern 第三方 UI 扩展。它既可以在 Chrome / Edge 中打开浏览器小窗，也可以作为“隐窗伴侣”桌面程序与酒馆页面之间的本机通信桥接。

## 功能

- 小窗显示当前聊天中最新一条非用户、非系统消息。
- 继承 SillyTavern 当前 UI 主题的主要颜色、边框、按钮和文本风格。
- 支持 HTML 美化内容渲染，并兼容常见前端卡片内的点击交互。
- 小窗内提供输入框，支持 `Enter` 发送、`Shift + Enter` 换行。
- 支持 `Send`、`Retry`、`Stop` 三个操作按钮。
- 右下角入口按钮可拖动；再次点击入口按钮会关闭已打开的小窗。
- 支持连接“隐窗伴侣”，同步酒馆助手已经渲染完成的 HTML/CSS 界面。
- 桌面端可以回传 Send、Retry、Stop 和常见选项点击操作。

## 设置

在 SillyTavern 的“扩展程序”设置页中，可以找到“隐蔽小窗”选项栏。

- 背景外观：可选择跟随酒馆主题或使用自定义颜色，并将背景不透明度调整到 0%（插件背景、边框和按钮底色完全透明）。
- 字体外观：可选择系统字体、微软雅黑、宋体、楷体或等宽字体，并调整字号和文字透明度。
- 隐蔽模式：鼠标移出小窗后插件内容完全不可见，移入后只恢复文字和控件，不恢复插件背景色块。
- 外观设置会实时应用到已打开的小窗，并自动保存在当前浏览器中。
- 兼容发送拦截插件：开启后，小窗发送前会向主页面发送按钮发出一次发送意图信号，用于兼容数据库、剧情规划等会拦截发送流程的脚本。

一般情况下可以保持关闭；如果你使用的小酒馆脚本需要监听主页面发送按钮点击事件，建议开启。

## 隐窗伴侣连接

使用桌面透明窗口时，不需要打开浏览器原生小窗：

1. 先启动“隐窗伴侣”桌面程序。
2. 点击桌面窗口右上角齿轮，在“本机连接”中点击“复制配置”。
3. 打开 SillyTavern 的扩展设置，展开“隐蔽小窗”。
4. 在“隐窗伴侣”区域的“快速导入”中粘贴配置。
5. 点击“应用连接配置”。
6. 插件显示“已连接”、桌面窗口显示“酒馆已连接”后即可使用。

如果桌面端仍显示欢迎页内容，先在酒馆中进入具体角色聊天，再点击插件设置中的“立即同步当前聊天”。插件也会定时检查活动角色和聊天变化，自动补发漏掉的切换事件。

酒馆助手的前端代码块通常在 iframe 中执行。插件会读取 iframe 已经执行完成的最终 DOM、样式和资源地址发送给桌面端；桌面端不会再次执行消息里的脚本。

如果前端 iframe 尚未加载完成或浏览器阻止读取，插件不会再把“显示前端代码块”和加载脚本当作最终内容发送，而会暂时显示消息中 `<w2g>` 的原始选项；iframe 可读取后会自动替换成最终界面。

通信服务只允许本机回环地址，并使用随机令牌验证。桌面程序负责透明窗口和输入操作；本插件负责读取酒馆助手渲染后的页面内容，以及执行酒馆、MVU 和页面按钮操作。

## 安装方式

1. 打开 SillyTavern。
2. 进入“扩展程序”页面。
3. 点击“安装扩展程序”。
4. 输入本仓库地址：

```text
https://github.com/yumicchi/mini_char_pro.git
```

5. 安装完成后刷新 SillyTavern 页面。
6. 在右下角点击“隐蔽小窗”按钮，或在扩展菜单中打开小窗。

## 浏览器要求

- 推荐 Chrome 或 Edge。
- 需要浏览器支持 Document Picture-in-Picture API。

## 注意事项

- 浏览器自带的 PiP 标题栏和窗口边框无法被插件主题化。
- Chromium 会强制显示来源地址栏，并可能为透明网页内容填充系统底色；插件无法让原生 PiP 窗口真正透出后方网页或桌面。
- 小窗不会复制完整 SillyTavern 页面，只保留最新回复、输入和基础操作。
